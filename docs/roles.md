## 김미리 — GitHub 관리·통합·발표

**담당 업무**
- GitHub 저장소 및 브랜치 관리
- 공통 실험 조건 설정
- 팀원별 전략 검토 및 최종 코드 통합
- 통합 전략 성능 검증
- 보고서 취합, PPT 제작 및 발표 준비

**최종 결과물**
- 통합된 `teams/A/MyStrategy.java`
- 기본·개별·통합 전략 성능 비교표
- 최종 보고서
- 발표 PPT 및 발표 대본


## 공통 협업 규칙

1. 각자 담당 브랜치에서 `teams/A/MyStrategy.java`를 수정한다.
2. 기본 엔진과 실행 관련 파일은 수정하지 않는다.
3. 전략 개발 후 PR을 생성하고 실험 결과를 공유한다.
4. PR은 검토용이며, 최종 통합 전 임의로 main에 병합하지 않는다.
5. 모든 실험은 공통 조건을 사용하며 실패 사례도 기록한다.
