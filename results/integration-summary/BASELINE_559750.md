# 제조 보고서 기준값 559,750원 조사

팀원 원본 보고서(`reference/`)와 PR #4 브랜치는 수정하지 않았다. 아래는 **보고서 기록**과 **통합 재현 수치**를 구분한 조사 기록이다.

## 수치 비교
| 구분 | 기준(기존 전략) | DP 전략 | DP − 기준 |
|---|---:|---:|---:|
| 제조 보고서 기록 (유호승, PR #4 CSV·그래프) | 559,750 | 561,000 | +1,250 |
| 통합 재현 (공개 시드 2026~2030, 20경기, 상대 main 기준 전략) | **557,500** | **561,000** | +3,500 |

## 보고서에서 확인된 조건
- 시드 2026~2030, 전략별 20경기, 상대 B = 기본 전략, `node run.js --benchmark`, 자리 교체·좌우반전 적용 (보고서 3절·그래프 하단 문구).
- PR #4 코드의 부모 커밋은 main `7882840`이고 변경은 `teams/A/MyStrategy.java`와 결과 CSV뿐이다. 즉 기준 코드가 main의 `teams/A`와 같은 파일에서 출발했다.
- 보고서와 CSV에는 경기별 원자료, 실행 로그, `teams/B` 파일 내용, 집계 방식(어느 팀의 몇 개 행을 평균했는지)이 없다. 전략 A·B의 코드도 PR에 없어 558,300·556,800은 재현할 수 없다.

## 같은 조건 재현 결과
- 기준끼리(main vs main) 20경기: 자리·반전별 평균도 556,600~558,400이고 전체 평균은 557,500이다. 접수·홍보 보고서의 기준(557,500)과 일치한다.
- 이번 재현에서 PR #4 코드는 561,000으로 보고서의 DP 수치와 일치한다.

## 원인 가설 검증 (모두 559,750을 만들지 못함)
| 가설 | 확인 방법 | 결과 |
|---|---|---|
| 상대 전략이 달랐다 | main을 상대 {PR #3 코드, PR #4 코드, 통합 접수ON}과 붙임 | 자기 팀 평균은 모두 557,500 (PR #2 코드를 상대로 하면 558,700) |
| 양 팀 평균으로 집계했다 | PR #4 vs main에서 양 팀 평균 | 559,250 (PR #3 vs main은 558,950) |
| 기준 코드에 마감 필터가 있었다 | main + "마감 내 못 끝낼 제조는 시작하지 않음" 변형(임시) | 공개 557,500, 신규 4001~4020 562,525로 main과 동일 |
| 자리·반전 일부만 집계했다 | main 자리·반전별 평균 | 556,600~558,400 (559,750 없음) |

**결론: 559,750원이 나온 원인은 확인하지 못했다.** 위 가설들은 모두 기각됐고, 기록 오류인지 당시 기준 코드·상대·집계 방식이 달랐는지는 알 수 없다. 원인을 확정하려면 유호승의 당시 실행 로그나 `results/comparison.json`, 기준으로 쓴 `teams/B` 파일이 필요하다. 비교 해석에는 동일 조건에서 재현한 기준 557,500원을 사용한다.

## 참고: DP 이득의 출처
- 위 "마감 필터" 변형은 main과 같아서, 마감 직전 못 끝낼 제조를 건너뛰는 것만으로는 이득이 생기지 않았다.
- 한편 SJF(동률이면 앞 주문 우선, 게이트 OFF)는 −1,800원이고 DP(그 조합에서 제조시간이 짧은 주문, 동률이면 뒤쪽 주문)는 +3,500원이었다. DP의 이득이 조합 탐색 때문인지 동률 처리 때문인지는 분리 실험을 하지 않아 확인하지 못했다.
