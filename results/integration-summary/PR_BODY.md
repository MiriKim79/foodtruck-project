## 3. 최종 채택 전략

`ORDER_GATE=false`, `COOK_MODE="DP"`, `PROMOTION_LIMIT=false`, `PROMO_END_MARGIN=4` → 접수는 기존 방식, 제조는 DP, 홍보는 기존 방식입니다. 우선순위(제조 > 접수 > 홍보), 작업 중 KEEP, 같은 작업 중복 배치 금지는 유지했고, 설정 4개는 코드 상단 상수로 독립적으로 바꿀 수 있습니다(미사용 분기는 비교 재현용으로 남겼습니다).

**선정 이유**
1. 공개·신규·홀드아웃 세 집합 모두에서 main 대비 하락한 시드가 없습니다.
2. 접수 게이트(ON)보다 신규·홀드아웃에서 일관되게 높았습니다. 게이트가 켜져 있으면 제조 모드를 바꿔도 매출이 같았습니다(공개 C2=C3=C4, 신규 C2=C4). 환불은 매출에서 빠지는 손실이 아니라 환불 0원은 목표가 아니었고, 접수를 거절하면 마감 직전 선택지가 줄어드는 것으로 추정합니다(별도 실험으로 검증하지 않았습니다).
3. 제조 직원이 경기당 약 99.9% 가동되어 제조 처리량이 병목이며, 개선 폭은 0.6% 수준입니다.

## 7. 알려진 한계

- **다른 상대 전략에 대한 검증은 하지 않았습니다.** 모든 실험의 상대는 main 기준 전략 1종이고, 공식 비공개 시드·상대의 성능도 확인하지 못했습니다.
- 개선 폭은 +0.6% 수준입니다. 최종 후보는 공개·신규 시드로 선정했고, 홀드아웃은 선정에 쓰지 않았습니다.
- **홍보 제한은 홀드아웃에서 검증하지 않았습니다.** 공개 +400, 신규 −350(CI [−875, +100])으로 일관된 근거가 없어 채택하지 않았습니다.
- **PR #4 보고서의 기준값 559,750원은 동일 조건(공개 시드 20경기, main 기준 전략)에서 재현하지 못했습니다.** 같은 코드끼리 붙이면 557,500원이었고 PR #2·#3 보고서와 일치합니다. 상대 전략·집계 방식·마감 필터 등 4가지 가설을 확인했지만 559,750원이 나오지 않았고, 원인은 확인하지 못했습니다(기록 오류로 단정하지 않습니다). 같은 기준(557,500원) 대비 DP의 개선은 +3,500원이며 PR #4가 보고한 DP 점수 561,000원은 재현됐습니다. 조사 내용: [BASELINE_559750.md](https://github.com/MiriKim79/foodtruck-project/blob/feat/integration/results/integration-summary/BASELINE_559750.md)
- DP의 이득이 조합 탐색 때문인지 동률 처리 방식 때문인지는 분리하지 않았습니다(동률 시 앞 주문을 우선하는 SJF는 −1,800원).
- 환불 주문이 경기당 약 4.4건 남지만 환불은 매출에 포함되지 않습니다. 마감 불가 주문만 거절하는 완화형 게이트는 실험하지 않았습니다.
